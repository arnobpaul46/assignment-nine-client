# DocAppoint - Advanced Doctor Appointment Manager

**DocAppoint** is a futuristic and highly secure medical appointment booking platform. It connects patients with verified medical specialists instantly, providing a seamless healthcare management experience.

### 🌐 [Live Site URL](https://docappoint-a9-arnob.vercel.app)

---

## 🚀 Key Features

- **Secure Authentication:** Integrated with **Better Auth**, providing robust Email/Password and Google Social Login with JWT-based session management.
- **Dynamic Doctor Discovery:** Browse through a comprehensive list of verified specialists from 15+ different medical departments.
- **Advanced Filtering & Search:** Search doctors by name and filter by specialty to find the right expert in seconds.
- **Personalized Patient Dashboard:** A secure private route for users to manage their appointments (view, update, or cancel) and customize their profiles.
- **Real-time Slot Booking:** Interactive booking system that prevents duplicate appointments and manages doctor availability dynamically.
- **Responsive Futuristic Design:** A premium dark-themed UI built with Tailwind CSS, ensuring a perfect experience across mobile, tablet, and desktop devices.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js (App Router), Tailwind CSS, Framer Motion
- **Backend:** Express.js, Node.js
- **Database:** MongoDB Atlas
- **Authentication:** Better Auth (JWT & Session)
- **Icons:** Lucide React, React Icons
- **Notifications:** React Toastify
